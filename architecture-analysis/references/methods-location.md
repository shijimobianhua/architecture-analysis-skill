# 区位与场地：可选表达方法

**适用材料**：任务书或地点说明，加真实地图、总图、卫星图等可定位依据；仅有风格图不能当地图。先锁定项目位置、方向、道路/水体和边界，缺关键材料才询问。

没有底图时可按 [定位与底图获取](location-sources.md) 由智能体查找地点、获取适合范围并保留坐标来源；不要求客户每次手工找图。道路/设施联系优先普通地图，地表肌理/建成环境优先卫星底图，不默认两种都下载。地点多义、坐标体系未知或红线缺失会影响本图结论时才询问。

**可选表达**：需要解释尺度关系时用定位小图与主地图；需要解释到达联系时突出道路层级、入口与节点；需要解释周边关系时使用位置对应的节点和简短标签。按本图问题选择，不默认同时包含这些模块。插画感可来自地图简化、线条、阴影与符号，无需补通用建筑主体。

**事实边界**：保留原始几何与共同坐标。无比例尺或可核对尺度，不加真实距离圈、面积或步行时间；不以视觉环带暗示已验证距离。客户边界不能由周边公开地图推断。照片和地标身份需有依据，外部参考不提供本项目地点事实。

**常见错误**：用生成城市替代真实地图；项目点漂移；周边节点与连线无对应；多级定位挤小主图；为填画幅加无关建筑。

**局部修正**：错名改文字，定位/连线错误改覆盖层；底图错位先检查共享变换。修改地图范围时同步重判锚点、标签与结论，不只搬动红点。既有底图可靠时无需AI重画地图。配色、图幅和布局遵循当前要求。

## 选定道路与场地表达
按 [道路高亮与标记](road-highlights.md) 把每条选中路段作为完整对象。默认连续路幅色带，有轮廓填路幅、只有中心线则单条粗实线；不逐车道反复描边、不把所有道路染成强调色。明确选择理由、起终范围、接续与终止依据；底图道路只是背景，到达箭头另有含义。场地用清楚的点/环，可靠红线才支持范围面，不能把点位扩大成整街区。检查完整路径而非只检查锚点，异高程交叉不臆断连通，路名不造成高亮缺段。
