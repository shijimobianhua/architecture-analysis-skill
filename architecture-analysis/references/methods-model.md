# 模型：已有视角中的空间关系

**适用材料**：模型/轴测截图与任务书功能说明；截图负责可见几何，文字不能替代隐藏几何资料。多个视图明确对应同一方案时结合使用，不因新参考图出现就丢弃仍有效的底图。

**可选表达**：在已有视角上用轮廓、透明色块、层级连线和标签解释可见体块、公共空间或设计意图。模型本身可作为主体；不另造通用建筑替代客户模型。新视角、剖切、爆炸仅在资料能支持对应几何时制作，不设默认爆炸层数。

**事实边界**：记录底图变换与可见锚点，保持体块数量、轮廓、相对位置和遮挡关系；不凭外观补结构、房间或楼板。材料不足则询问最少必要视图，或由用户选择已有视角可支持的表达。示意箭头不能冒充模拟结果。

**常见错误**：风格化重绘改变体块；隐藏结构被“合理”补出；标签指向被遮挡对象；分析线漂浮或穿错楼层；套竖向爆炸模板改变用户画幅。

**局部修正**：错标签、指向、覆盖色分别改对应层；原截图不清晰时请提供更清晰原图，不能放大后称原生高清。若更换视角则重建相关锚点与覆盖关系，不能只换背景图。当前参考决定线条、颜色和材质处理，不能覆盖几何依据。
