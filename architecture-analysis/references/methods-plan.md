# 平面：原图与分析覆盖

**适用材料**：可读平面/总图，以及支持当前分析的功能、入口、道路、方向等材料；只要求本图实际需要的信息，不为普通分区额外索要模型。

**可选表达**：分区用对应功能范围的色块；流线用入口—可通行路径—目的地的线与箭头；节点用锚点和短标签；视线用有依据的观察点、目标及已知遮挡。可组合必要层，不固定图例位置或布局。

**事实边界**：原图锁定，记录等比变换；分析锚点共用同一坐标与变换。不重绘房间、门、路，不穿实体；无尺度不能算真实距离/面积，二维视线不当三维视域。低对比或灰度处理不能擦去必要入口和边界。

**常见错误**：底图与箭头各自居中；填色越过功能边界；为风格重画出不同墙线；标签遮住入口；放大图形时漏改覆盖层。

**局部修正**：修复对应锚点/路径/色块，标签单独避让并检查字号；若底图或入口改变则重新核对关联分析。回看原图，不把AI相似外观当保真证明。适配画幅先调组织和整体等比位置，不拉伸、缩字或裁掉必要范围。
