# 订单交付与记录

接单最小信息：图种/张数、任务书与必要底图、画布或像素尺寸、风格、用途、交期、约定修改范围。仅问缺失且影响本单的内容。交期、收费和修改轮次未知时留空，不擅自报价或承诺无限修改。

出图前检查每图核心问题与依据，选择必要素材与图形，优先利用现成资料，避免无关建筑插画及重复生成；交付时给整图预览、实际尺寸、分层顺序、导入方法、内容依据/定性部分、修改能力和未完成项。客户默认只拿图片；内部保留输入、资产、内容/风格参数、图层映射、工具与运行记录供改稿。

新订单的 [简短视觉方案](visual-planning.md) 并入现有内容/风格整理；已有对应记录直接引用，不重复填写。方法卡随技能安装，正常订单不访问其来源仓库、不另做母版合同或百分制评分。无实际图片检查的脚本分数不能当成画质证据。交付接口和订单schema不变，视觉方案仅为内部记录。

默认由用户检查PS，订单qa分开记录automatic_checks与photoshop；后者默认pending_user。历史PS记录不得复制成本单通过，不逐单安排额外改字测试。交付前检查有效图形是否充分展开到画幅，减少影响展板拼贴的无用途外围空白。

记录内容整理、主动制作、工具等待、质检、改稿与总历时；可重叠事件不直接相加。未知或未独立计时留null，导出脚本执行时间不是全部人工改稿时间。记录实际生成次数和成本，工具未返回费用留null，不默认为免费。

区位取图仅在需要时执行，网络检索与地图下载的等待/次数另记，已缓存原图可复用。内部保留定位证据、坐标体系、原始底图及map.json、实际绘制框与控制点核对、获取时间与已知影像日期、署名和使用依据；未知拍摄日期、费用留空。来源要求署名时随图片保留，不能只放内部说明。客户交付仍为整图和实际分层，不默认发送原始服务响应、密钥或内部地址记录。不得把公开可访问等同于商用授权。旧订单不强制补地图记录。

“换词/改色/替换素材”与“新增人群/重写逻辑/换整体风格/改变方案”分别记录，范围变化先说明影响。不替用户联系客户、发布到小红书、购买或注册服务。首图、跨风格复用、客户付费与验收分别记录，技术通过不代表商业成功。

出图前集中确认缺失的字体与各实际层级字号/单位，默认300PPI，不主动询问印刷物理尺寸。纯色图只提供尺寸，默认白底。交付说明可记录假设和限制，但画面不放制作备注。评审后一次选择式收录经验，未获同意只保留本单候选。

新单将密度与文字集中确认，已有选择或明确授权直接记录；辅助色若需要另记录色样、用途、位置和同意，沉默不算同意。内部保留预排结果、锚点/允许重叠与偏移、必要搜索的事实/方法来源。交付记录区分技术复原、信息充分、语义几何及视觉统一，未看图不填人工通过；必要搜索等待与预排耗时分别记，未知留空。旧单读取和验收不强制补表。

3.1.1视觉连续性结论并入现有视觉统一记录，无新增客户必填项。底板或模块有阅读/分组用途并适配整体时可用；满版新增内容先重组，只有明显改变既定背景逻辑、大面积独立区或已确认规格冲突时具体询问。局部改稿不擅改字号、画布或密度目标，不用“换成灰框”代替构图修复。

3.2区位道路交付内部记录选段、几何依据、路幅/中心线表达、终点理由及连续性/贴合/主次检查。说明表达线宽不是测量值、定位环不是红线，参考完整性未核验时不标通过。新工具不新增客户必填项或调查费用承诺；道路生成次数与本地处理耗时可记，不能当完整出图时长。旧订单无需补记录才可读取和验证。
