# Photoshop 同坐标导入

所有PNG相同尺寸仍不足以保证任意拖放方式对齐：PS可能按透明内容边界居中，或把文件置入为自动缩放的智能对象。默认由用户核对实际导入效果，智能体不启动PS；用户明确要求代测时才执行目标版本实测。自动PNG检查通过不能写成本单PS实测通过。

推荐使用本包 scripts/import_layers.jsx：在PS选择“文件 > 脚本 > 浏览”，运行脚本并选择客户交付目录。脚本根据manifest.json打开背景全画布，逐层复制到同一坐标，恢复不透明内容的原始边界偏移，使用正常混合和100%不透明度，不裁切画布。保留用户原有文档，不关闭或覆盖它们。

手动方式：先打开背景PNG，再把各全画布PNG分别打开，用“图层 > 复制图层”送到背景文档；复制后核对四角、文字与线条。不同版本由用户核对实际行为，不把未经验证的拖放步骤写成保证。

以下既有实测和 validation-status.md 中的历史结果仅供方法参考，不是后续订单的验证结果。文字PNG是栅格层，能调色、移动、隐藏和替换，不能用PS文字工具直接改字。需要重新出字时由制作方从内部来源导出同坐标文字PNG。

2026-10-29实测：Photoshop 24.3.0，五层2400×1600。脚本导入并导出PNG后，与完整图逐像素相同，最大通道差0。用户也报告逐张拖入对齐成功。手动拖入记录只代表本次环境；其他版本或首选项出现缩放/居中时，使用脚本保留坐标。脚本读取磁盘临时副本，避免修改用户已打开的同名输入文档；完成后清理其创建的临时输入文件。
