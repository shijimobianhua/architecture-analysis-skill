# 多层级文字确认与300PPI

先理解本图内容和文字层级，再将实际需要的规格集中问一次，例如：“本图有客群小标题、正文、图例三类文字，请分别给字体/字重/字号和pt或px；统一字体可以只给一次。”不固定每张图都四层级，不新增整图标题。不重复问本轮已经明确的值；“你定”也是授权选择，给出具体方案并记录授权来源，无需再次确认。

记录字体家族、字重、实际字体文件、size、unit和本单确认来源。统一字体可在输入时展开到各角色；不要默默继承上次的字号。发现字体缺失，给可用候选并等待选择；不能靠系统fallback替换。文件中的weight表示实际选定字重；helper不合成伪粗体。

PPI默认300，可更高；不进行印刷物理尺寸询问或打样检查。pt换算为px=size*PPI/72，px按输入像素。例如300PPI下12pt=50px，12px仍为12px。各角色独立设置，pt换算保留小数，由支持浮点字号的字体渲染器直接绘制；不把整张文字层先低分辨率画出再放大。

字体在最终像素画布重新栅格化并保留抗锯齿。300PPI只说明元数据与pt换算，不保证低分辨率插图变清晰，也不承诺任意放大输出。字体较小或内容较多时做100%与缩放检查。

排版超出指定范围时，展示冲突并让用户选精简内容、换结构或修改字号/画布；未经明确选择，不缩字、不放大画布、不删减。质检记录实际字号/字体、越界、遮挡及原尺寸可读性，不设印刷规格验收。

密度与字体在本单集中确认，方法见 [容量与密度](layout-density.md)。已明确字体时只补问未明确的密度，不重问字体；“你决定”记录授权后选择，不再确认。预排复用与最终绘制相同的字体测量，画幅/字号同比变化不自动增加内容；不能用缩字实现丰富档。
