# 已执行验证（2026-10-29）

## 实测通过
- 总入口和六个子skill均通过skill-creator官方quick_validate，UTF-8编码；元数据启用正常自动发现。
- 14项行为测试通过：同画布纯色输入、尺寸冲突、真实透明空间、文字越界、完整图篡改检测、图层尺寸错误、保留旧交付、空层省略、库收录需授权、同意收录与重复去重、拒绝后不重复提醒、客户材料独立授权、输出路径边界及内部链接。
- 通用路线实际制作：暖色拼贴与蓝色建筑线稿，两套2400×1600，均无整图标题/项目名/编号/章节条。六格AI素材供人物和场景使用，中文和曲线独立排版；未把蓝色新样例未经同意加入正式参考库。
- 人群改稿只替换通勤居民需求“短时停留→便民服务”；变化边界(1251,300)—(1363,328)，背景、场景、色块、线条文件完全不变。
- 两套风格、改稿、平面与模型测试图均交付五层全画布PNG，RGBA/透明边界、统一sRGB/DPI、重组检查通过，重组与整图无像素差异。
- 平面和模型使用明确标记的简化人工测试输入，原底图像素与Alpha分别核验不变，覆盖层共享坐标。人工检查流线位于两翼之间可通行区；模型只表达可见顶面与两个体块。
- 模型缺视图测试：请求背面剖切而只有单张当前视图，按子skill给出需补对应剖面/模型视图的问题，不制作隐藏结构。此项是当前执行者的情景走查，未声称独立模型评测或真实复杂模型通过。
- Photoshop COM实际版本24.3.0。使用import_layers.jsx导入五层，PS导出仍为2400×1600，和最终图逐像素一致（最大通道差0）。用户另反馈“挨个拖入对的上没问题”，作为用户报告的手动拖入通过记录。

## 验证边界
尚未验证任意复杂方案、所有PS版本/首选项、其他中文字体、任意图幅排版、真实印刷占位或真实付费订单。蓝色样例验证了新的素材与配色表达，但沿用同一内容结构，不代表任意构图都已实测。

工具不负责理解图纸，几何与内容仍须智能体按任务书检查，必要时由建筑专业使用者复核。PNG图层不是原生文字或路径；客户默认不收生产源码/PSD。

## 发现并修正的问题
- 不同进程创建的sRGB配置字节可能带不同生成时间，验收改为检查配置描述及同批图层一致性，不与新建配置逐字节比较。
- JSON颜色数组在绘图前转换为像素工具接受的形式。
- PS脚本通过临时输入副本导入，避免碰到用户已打开并修改的同名文档；恢复尺规和对话框首选项，不关闭用户原有文档。
