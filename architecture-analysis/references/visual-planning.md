# 本单视觉方案与依据对应

并入已有解读和风格适配，不新增独立阶段或草图确认；本单密度并入字体集中确认。新图在internal/visual-plan.md简记以下内容；已有记录足够则引用其具体位置，不复制正文。旧订单无需补填才能读取、验证或改稿。

- **材料与路线**：引用任务、内容方案、画幅和确认字体，区分事实底图、风格参考与尺寸图；记所选方法及理由。
- **四组视觉判断**：表现手法（简化、线条、阴影纹理）、视觉层级（主次与颜色意义）、图形组织（阅读、连接、标注、疏密）、适配边界（可借鉴特征、不可迁移事实、随本单调整的数量/比例/位置）。口述足够时采用，不强求参考图。
- **关键元素**：对象/位置 → 表达含义 → 材料与依据状态 → 图形和交付层。同依据符号可成组记录，不逐个装饰点建账；引用原图锚点与共同变换，不以美化掩盖缺口。
- **制作与修改**：区分复用素材、直接绘制的文字/几何、确需生成的插画；一个主方向。改稿定位对象与层，复用无关部分，不重复记来源/提示词。

按本图选择 [区位](methods-location.md)、[人群](methods-people.md)、[平面](methods-plan.md)、[模型](methods-model.md)，无需读完全部卡。通常一组，复合图最多两组，批量不同图分别选择。无匹配仍按材料制作，不编造方法ID或因缺模板停止。

方法不固定配色、字体、布局、比例或元素数量。新参考优先，不因高频风格形成默认，也不丢弃仍有效的任务和底图。构图遵守完整画幅与确认字号，不拉伸或裁关键范围。

沿用总入口的质检与自动分层验收，不新增评分、母版合同、逐单PS或假改稿。看实际图质检，局部无法解决才扩大重做范围，不以省次数保留错误。卡片本地按需读取，与经验授权分开；正常订单不访问来源仓库。追溯时读 [来源与取舍](third-party-sources.md)，普通订单无需读。

按 [容量与统一性](layout-density.md) 简记密度与授权、核心/支撑/可深化信息、主辅和标注区；颜色扩展记录具体色样、用途、位置及单独同意。布局工具输入留内部，可引用现有源记录；不为字段重复问客户。关键覆盖层记录原图对象/锚点、实际变换及允许偏移，几何检查和视觉检查分别记录；检索事实与方法分别追溯，不自动收录。
