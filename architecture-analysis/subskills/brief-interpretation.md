# 任务书解读

适用于每单开始，以及需求或方案发生变化时。

读取实际任务书、附图及客户口述，不把示例项目当本单需求。提取：设计目标、场地条件、使用者、方案事实、限制条件、交付范围、需要图解释的问题。任务是将材料转成可用的分析逻辑，而不只是摘词。

形成简短内容方案，每条包含“依据/位置 → 分析内容 → 可支持的结论或空间响应”。标记provided（客户提供未独立核验）、verified（已核验且有来源）、hypothesis（定性推演）、unknown（缺失）。客户意图与专业推演分开记录；不同图不必都强行画空间策略。

为关键分析元素补充“对象与位置、表达含义、材料依据、图形及交付层”，按 [视觉方案](../references/visual-planning.md) 与已有内容方案互相引用。同一依据支撑的重复符号可成组记录，不逐像素建账。箭头要能找到起终对象与路径依据；色块要说明代表范围、功能还是重点。对应关系留在内部，已有记录足够就引用，不复制一份。

检查结论是否超出材料：流线必须有可通行路径与入口；视线应有观察点、目标和遮挡依据；功能分区需有方案功能；需求不能被写成真实调查；模拟结果不能由意图箭头替代。

展示本单要画什么、关键依据、定性部分和采用的路线。选出真正支撑本图问题的视觉对象；任务书的功能清单不自动变成一组建筑插画。资料足够即继续；只有会改变结论/几何/范围的未知或冲突才询问最少问题。缺失模型不妨碍通用分析；缺失必要几何则不能假装方案分析已完成。混合订单先推进不依赖缺口的图。

用户排除的数据采集或计算模拟直接说明不在范围，可请客户提供现成结果。现成数据也需检查单位、年份/时间、总量和结论是否一致。

区位订单从任务书提取城市、地址/路口、方位、已知地标和项目边界依据。若只有地点而无底图，可由智能体按 [定位与底图](../references/location-sources.md) 检索位置并获取真实地图；公开地理资料检索不等于代做调查。先核对地点再画红点，街道/区县级匹配不当成精确地块，定位点不能替代用地红线。已有可靠底图直接用，不为新功能重新联网。

背景、300PPI、文字确认与图面内容沿用 [总入口](../SKILL.md) 和 [文字规格](../references/typography.md)。本流程改进合并至本单一次 [经验评审](../references/library-policy.md)，不独立询问或按频率改变默认。

## 内容层级与必要补充
在既有依据方案中标记必须表达、支撑信息、可深化内容；丰富档可深化同主题的活动、节点和关系，不主动添加无关专题。资料不足且客户无更多材料时按 [容量与密度](../references/layout-density.md) 进行有限定向搜索，分别记录项目事实与表达参考；后者不能提供本项目事实。足够就跳过，冲突/过时/未核实资料不直接采用，仍不足时说明能支持的范围，不造数据或用装饰补缺。

内容整理阶段区分适合图形表达与需要简短说明的内容，不默认把长段文字全放进图面。新增内容先归入既有对象/关系，减少重复表达；用户明确要求保留的内容不擅自删除。空间不足按已确认画幅与字号说明冲突，不把说明硬塞到白框或底栏。

区位选路时记录本图的重点道路/组件、分析理由、参考几何和起终范围；分析强调等级不直接等于真实道路行政等级。资料分段不意味着分析可以断段，地图边缘、真实路端、明确节点或有依据研究范围才能解释终止。道路高亮不代表已核验步行可达，场地点位/定位环不代表用地红线。
