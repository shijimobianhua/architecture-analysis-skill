# 通用分析图

适用于不依赖具体方案几何的人群、需求、行为、框架和问题策略，也承接有现成依据的历史、区位与统计表达。

区位/场地按需读 [区位方法](../references/methods-location.md)，人群/需求按需读 [人群方法](../references/methods-people.md)；其他题目无需硬套。方法卡仅提供可选组织方式，遵循总入口的读取预算；没有适用方法仍可依据材料完成。

区位缺底图时按 [定位与底图](../references/location-sources.md) 先定位、核对，再按问题选普通地图、卫星图或两者的必要组合。已有资料足够时跳过取图。地理骨架与文字/分析覆盖层共坐标；插画化可简化表达，但道路、水体、项目点与节点关系不交给生图工具任意重构。

根据本单问题选择信息结构，允许画像、关系网络、时间序列、逻辑链、矩阵或拼贴，不强制同时出现全部模块。说明每个视觉元素支撑的内容，避免装饰挤占分析。人群图优先人物、活动与需求关系；区位图优先有依据的地图、道路、地标和空间联系。插画风只规定表现手法，不默认附加通用建筑主体；没有必要插画时无需生图。有效图形充分展开到给定画幅，标签简短，留白服务阅读，不设宽页边距或固定图文比例。

人群与需求：以任务书或客户材料为依据；定性假设在内部来源和交付说明记录，不加图内制作备注，不增加年龄、比例、样本量或客流预测。活动节律用提供的数据或明确的手工示意参数，不能随机曲线冒充调查。

历史：日期、事件、照片身份需有材料；AI概念场景不得冒充真实历史照片。区位：真实地图、地点、方向、边界和设施关系需可核对，AI城市图不能充当地图。现成统计：忠实呈现提供的原始值、单位、口径和来源，缺口不自行调查或算模拟。

画面中仅保留理解所需标签、图例、时间和单位；不加图名或章节条。按选定风格制作无文字素材，中文和关系独立排版。最终走分层交付子 skill。

## 第二版共享要求

背景、300PPI、文字确认与图面内容沿用 [总入口](../SKILL.md) 和 [文字规格](../references/typography.md)。本流程改进合并至本单一次 [经验评审](../references/library-policy.md)，不独立询问或按频率改变默认。

密度按 [容量与统一性](../references/layout-density.md) 随本图画幅、字号和活动/关系展开程度判断。人群图可深化必要活动与需求连接，区位图可深化有依据的道路/节点；不能用头像数量、路网纹理或长段文字冒充信息丰富。必要搜索区分事实与表达方法，素材融入当前视觉方案。

区位重点道路默认按 [连续道路覆盖](../references/road-highlights.md) 制作：有可靠边界时连续填色，仅有中心线时单条连续粗实线；少量选择与场地相关道路，明确整段范围，不能画一半漏一半或逐车道叠线。完整道路透明层可用road_overlay.py生成后接原分层，不依赖新生图。场地定位与用地范围分开，点、环、范围和到达箭头不混用；本单参考仍优先。
