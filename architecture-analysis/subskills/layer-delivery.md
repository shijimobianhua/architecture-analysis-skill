# 分层交付与质检

适用于制作前的分层规划、最终导出、改稿与PS交接。

默认类别自下而上：背景 → 底图与场景 → 分析色块 → 分析线条 → 文字标签。只输出实际存在的非空层；确有独立编辑任务时在类别内细分。图例符号进对应色块/线条层，文字进文字层，共享坐标。不要把图名、项目名或章节条放入文字层。

从制作时分层，不从已合并成图强行抠文字作为默认办法。背景层可不透明，其余层使用RGBA和真正透明的空白；图纸内部可以是有意义的不透明像素。所有层保留完整画布尺寸、(0,0)原点、相同分辨率信息与sRGB；不裁边、不单独居中、不自动缩放。采用正常混合和100%图层不透明度，局部透明效果烘入像素Alpha。

依 references/layer-tool.md（相对于总skill目录）使用导出/验收工具，或用其他工具满足同样不变量。最终完整图由实际交付层按顺序合成，独立重组应像素一致。客户包只含整图、分层PNG和必要的导入/内容说明；制作参数和脚本放内部来源目录，不默认交付PSD或源码。

必检：整图、100%关键细节、目标缩放；中文/数字/时间/单位、图例、结论与依据、人物/场景、画幅利用、真实像素。方案图另检几何与锚点。仅检查实际像素、原尺寸与缩放可读性；不新增印刷规格检查或询问物理尺寸。

不逐单安排虚构改字或额外改稿测试。代表性改字回归用于技能升级、相关交付工具变化或出现异常时；真实改稿只检查受影响部分及非目标区域是否保持不变。是否重新生图、导出执行和人工改稿耗时分别记录。PNG文字不能直接用PS文字工具改，需内部来源重出文字层。禁止用图层数量冒充内部对象可编辑。

改稿先查内部视觉方案中的对象—依据—图层对应。错字/字号/位置只重出文字层；箭头/连线/图例符号修改线条或所属符号层；分区色与透明度修改色块层；人物/场景问题只替换相关素材；逻辑或底图变化先重判影响范围。未受影响层直接复用，再从实际交付层合成与检查；不为一次小改重复生成所有素材，也不能为省次数保留错误。确需重出整个文字层时，不把文字层重绘误称整图重生。现有工具compose可能重新写出完整交付集，需区分确定性导出与AI重生；工具用法不变。

默认不启动Photoshop，不逐单实测导入；用户检查实际PS效果。提供保留全画布原点的导入脚本和方法，拖放可能按透明内容居中或自动缩放，不能仅凭相同尺寸承诺任意拖法对齐。用户明确要求代测时再按 references/photoshop-import.md 执行。

必须保留事实、几何、文字、遮挡/越界及画幅利用检查，以及尺寸、PPI、透明度、同坐标叠加复原的自动检查。检查有效图形是否充分展开、边缘空白是否有阅读用途；不以底色覆盖或无关装饰充当画面利用。订单qa中automatic_checks记录本次真实自动结果；photoshop.status默认pending_user，不能根据历史实测自动标记通过。用户反馈通过时可记user_reported_passed并保留反馈依据；本单另获要求并实测通过才记tested_passed。

## 第二版共享要求

使用外部地图时，核对原始底图、实际返回范围/尺寸、坐标体系、至少两处可识别控制位置及覆盖层变换；仅在中心放红点不算全部定位已核验。地图裁切、范围或放置框变化后同步更新点线文字坐标，不能独立缩放。保留来源要求的署名/版权标识，它们属于素材使用信息，不是整图标题或制作备注。未取得可信范围的截图不添加精确比例尺、真实距离圈或步行时间；原始图像清晰度不因最终300PPI改变。详细记录见 [定位与底图](../references/location-sources.md)。

背景、300PPI、文字确认与图面内容沿用 [总入口](../SKILL.md) 和 [文字规格](../references/typography.md)。本流程改进合并至本单一次 [经验评审](../references/library-policy.md)，不独立询问或按频率改变默认。

## 预排、几何与视觉分开验收
按 [容量与整体一致性](../references/layout-density.md) 检查真实字号与分配区、局部标签拥挤、原图锚点及覆盖层变换；可用layout_check.py输出内部测量，缺结构化数据不假装自动通过。另看实际整图与100%局部的色块边缘、路径端点、标签指向、透明度、配色层级、人物/场景、阴影和素材融合。分别记录信息充分性、语义几何、视觉统一与PNG技术复原；技术通过不覆盖其他未完成项。真实改稿只重查受影响部分，密度变化不默认整图重生。

视觉统一验收同时按 [容器与连续性](../references/layout-density.md#视觉连续性与容器) 看整图：孤立白/灰块、突然底栏、说明抢主体、遮挡关键几何、容器体系不一致均需回到局部构图修正；只换底板颜色不算修复。合法图例、来源标识、用户要求或整体成立的卡片分区保留，不按白色/矩形机械拒绝。预排与复原无法自动判断这些问题，未实际看图不标视觉通过。

道路覆盖层按 [整段检查](../references/road-highlights.md) 检查：漏段、重复、细缝、转弯/路口接续、终点依据、桥上桥下、与底图贴合及标签是否遮断路径。road_overlay.py报告仅检查提供的参考几何，不自动证明道路真实完整；栅格描绘与路幅面接缝仍实际看图。连续性、地理贴合、视觉主次、PNG复原分别记录，错误只改道路与关联标记层。高亮道路归分析线条，场地面归色块、轮廓归线条，文字归文字层。
