# 模型视图依赖分析图

适用于体块关系、空间层次、已有轴测截图及模型可见面上的设计意图。

按需读 [模型方法](../references/methods-model.md)，围绕实际可见对象选择表达；材料不足时方法卡不授权补出隐藏几何或任意爆炸层次。

确认截图视角、可见体块、地面/层级、入口等任务相关对象；任务书解释功能，截图提供几何，两者冲突先确认。屏幕投影长度不能直接当实际尺寸，不从一张截图推断隐藏面、结构系统或真实剖切。

默认在原截图的相同视角上叠加色块、轮廓、连接线和标签，记录底图位置与等比变换。保持可见轮廓、体块数量与相对位置。允许对底图做不改变几何的色彩处理，不用生成式重绘替换方案本体。

要求新视角、剖切、分解或隐藏关系时，先检查是否已有对应视图/模型；缺少则索取所需的最少视图，或经用户选择改为现有视角可支持的表达。禁止自造后宣称是客户方案。

风、日照、结构受力等箭头只能表达依据明确、性质在内部与交付说明记录的设计意图，不能画成已运行模拟的结果。客户现成结果可以作为独立底图表达，不运行计算。

客户模型本身可以是本图主体，不因取消默认建筑配景而削弱方案表达；不另造通用建筑替代它。围绕已有可见几何与分析关系充分利用画幅，避免宽边空白，不拉伸、不裁掉必要轮廓。

核对可见轮廓锚点、遮挡顺序、覆盖层与体块对应关系；保留原截图和共同变换。最终走分层交付子 skill。

## 第二版共享要求

背景、300PPI、文字确认与图面内容沿用 [总入口](../SKILL.md) 和 [文字规格](../references/typography.md)。本流程改进合并至本单一次 [经验评审](../references/library-policy.md)，不独立询问或按频率改变默认。

按 [容量与一致性](../references/layout-density.md) 用实际字号预排。分析色块/路径/节点对应原图轮廓与可见对象，底图变换后覆盖层同步；有结构化锚点可自动核对，仅有栅格时做人工检查。允许说明清楚的偏移图解和外置标签，不将贴合机械理解为所有元素重叠。丰富档不补造隐藏几何、入口或事实。
