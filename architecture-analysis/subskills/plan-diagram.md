# 平面依赖分析图

适用于功能分区、流线、节点、视线及依赖平面位置关系的方案分析。

按需读 [平面方法](../references/methods-plan.md)，选择适合本图问题的原图覆盖表达。方法不规定颜色、图幅或布局，也不能替代下述几何核对。

先确认截图清晰可读；辨认项目边界、建筑轮廓、开口/入口、道路/通道、功能、方向、尺度依据。只询问影响本图结论的缺口；不要求所有图都有完整模型或比例尺。像素可用于定位，不可在无比例尺时换算真实距离或面积。

以原图作为锁定的底图，记录其画布位置和等比变换。分析覆盖层与底图共享同一变换和坐标；禁止分别重新居中或非等比缩放。为适配风格可以降低底图饱和度/对比或叠加，但不能改变几何、擦掉必要入口或凭空增添道路。

分区应与功能依据对应；流线节点应位于可通行区域，不穿实体；箭头指向明确且图例一致。视线只有在观察点、目标与已知遮挡足够时表达，二维视线不能替代三维视域分析。没有几何推导依据时不当作几何结论，意图性质记在内部来源和交付说明，不加图内制作备注。

优先用原图与分析覆盖层承担画面，充分利用给定画幅，不附加无关建筑主体插画。不为填满画幅拉伸几何或裁掉分析所需范围，留白仅服务阅读和标注。

保留原始底图和已知锚点，核对轮廓、入口、道路和覆盖层位置。下游几何检查使用原图与共享变换，不把AI“看起来像”当保真证明。最终走分层交付子 skill。

## 第二版共享要求

背景、300PPI、文字确认与图面内容沿用 [总入口](../SKILL.md) 和 [文字规格](../references/typography.md)。本流程改进合并至本单一次 [经验评审](../references/library-policy.md)，不独立询问或按频率改变默认。

按 [容量与一致性](../references/layout-density.md) 用实际字号预排。分析色块/路径/节点对应原图轮廓与可见对象，底图变换后覆盖层同步；有结构化锚点可自动核对，仅有栅格时做人工检查。允许说明清楚的偏移图解和外置标签，不将贴合机械理解为所有元素重叠。丰富档不补造隐藏几何、入口或事实。
